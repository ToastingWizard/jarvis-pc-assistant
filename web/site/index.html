Get started

Download & run NaiTRO.exe

Grab the latest release from GitHub Releases. One file — no install wizard. First launch creates a local config.json.

Bring your own AI key (optional)

NaiTRO ships with no API key — by design. The launcher, voice control, and modes all work without one. For smart replies, grab a free key at build.nvidia.com (or Gemini) and paste it into Settings → Neural Uplink in the app.

Start talking

Click the orb, then say “hey NaiTRO, open chrome” or type commands in the box. Build a “study mode” that opens your calendar and notes, and watch it chain everything together.

Heads-up: NaiTRO’s interface runs on the Microsoft Edge WebView2 runtime. Most Windows 11 machines already have it; if you see a blank window, install it with winget install Microsoft.EdgeWebView2Runtime.
